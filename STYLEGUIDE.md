# STYLEGUIDE.md

## Insects / Bug Palette

This project utilizes an earthy, insect-inspired palette designed for high contrast and organic feel.

| Color Name | Hex Code | Purpose / Usage |
| :--- | :--- | :--- |
| **Chitin Black** | '#1a1a1a' | Primary text and dark elements |
| **Beetle Green** | '#2d5a27' | Headings, primary band elements, main buttons |
| **Amber Honey** | '#d97706' | Interactive links, focus indicators, warnings |
| **Mantis Lime** | '#84cc16' | Hover states, success indicators, highlights |
| **Chitin Light** | '#f4f4f0' | App background |

---

## Typography & Font Sizes

**Font Family:** `'Segoe UI', Tahoma, Geneva, Verdana, sans-serif`

* **Heading / H1:** `2.5rem` (`36px`) - Page titles
* **Subheading / H2-H3:** `1.5rem` (`24px`) - Section headers
* **Body Text:** `1.0rem`, (`16px`) - Default paragraphs and UI components
* **Small / Caption:** `0.875rem` (`14px`) - Metadata, footers, and hints
